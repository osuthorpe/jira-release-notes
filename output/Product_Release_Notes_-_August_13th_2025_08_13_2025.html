General Bug Fixes and Enhancements

  • Manage User External ID Restoration- We restored the ability to view the "external_id" on the Manage tab, which helps admins troubleshoot issues effectively.
  • Resolved Region Mismatch in EU Teams Integration- We fixed an issue causing integration problems due to mismatched regional settings for some systems.
  • Folder Rename Confirmation- You can now press Enter to confirm a folder rename in the pipeline sidebar, just like using Tab or clicking away.
  • Comment Type Selector Position Fix- We adjusted the comment type selector in the modal to display upwards rather than downwards to prevent it from being cut off at the bottom of the page, affecting some systems.
  • Quick Add Dropdown Padding Reduction- We reduced the right-side padding for options in the Quick Add dropdown to minimize dead space for some systems.
  • Memo Link 404 Error Fix- We resolved an issue causing a 404 error when linking a new memo to an existing one in some systems.
  • Corrected Tooltip for Development Steps- We fixed the spelling error in the tooltip for Development Steps where "Development" was incorrectly spelled as "Developement."
