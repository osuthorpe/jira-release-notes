Our latest product release took effect Thursday, October 9th, 2025. This post may be different from the release notes received via email.

General Bug Fixes and Enhancements

  • Phase Display Option in Scheduler- We fixed an issue where disabling the phase display option in the Scheduler did not save correctly, affecting some systems.
  • Submission Form Loading Fix- We resolved an issue where the submission form was not loading until the page was refreshed, which had affected some systems.
  • Request to Join Team Text Box Limit- We fixed an issue where the Request to Join Team text box was not respecting the 500-character limit for some systems.
  • View Idea 3 Widget Editor Button Visibility Fix- We resolved an issue where edit buttons in the right column were cut off, affecting some systems.
  • Administrator Message Panel Code Wrapping- We resolved an issue where adding code in the Administrator Message Panel settings resulted in all code being wrapped in paragraph tags, affecting some systems.

Whiteboard

  • Organize with AI on Whiteboard Enhancement- We updated the Organize with AI feature to work seamlessly when selecting multiple Stickies alongside other objects, by only processing Stickies and ignoring other object types.
  • Whiteboard AI Feature for Text and Long Form Docs- We enabled the "Build an App" functionality for Text and Long Form Document objects while removing this option from all other object types.
  • Whiteboard Layout Update- We adjusted the Long Form Document width to 612 pixels, retained margins at 72 pixels, and set font sizes to 10 for enhanced design consistency.
  • Marker Line Scaling- We added the ability to scale marker lines in the Whiteboard using the hotkey "K".
